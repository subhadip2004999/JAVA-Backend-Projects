# JAVA Backend Projects

This repository contains a collection of Java-based mini-projects and learning applications focused on core Java concepts, object-oriented programming, and graphical user interfaces (GUI).

The projects cover a range of topics including:
- Banking and finance systems
- Hospital and library management
- GUI-based utilities and games
- Interactive Java applications for practice and learning

## Project Structure

- ATM Interface
- Banking Management Sytem
- Hospital Management System
- Java GUI based
- Library Management System
- Number Guess Game
- Stock Trading Platform

## Included Applications

### Java GUI based
This folder contains small Java Swing/AWT-based applications such as:

Each project directory represents a separate Java mini-application or practice project with a specific purpose, such as:
- ATM simulation and transaction handling

- Stock trading platform workflow

## Tech Stack

- Java

- Java SE fundamentals

## Prerequisites

Before running these projects, make sure you have:
- JDK 8 or higher installed
- A Java IDE such as IntelliJ IDEA, Eclipse, or VS Code with Java support

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/subhadip2004999/JAVA-Backend-Projects.git
   ```

2. Open a project folder:
   ```bash
   cd JAVA-Backend-Projects
   ```

3. Compile and run a Java file:
   ```bash
   javac "Java GUI based/Calculator.java"
   java -cp "Java GUI based" Calculator
   ```

   Replace `Calculator` with the class name of the project you want to run.
